# Provenance and attribution

This repository started as an adapted copy of [suayptalha/s-means](https://github.com/suayptalha/s-means), retrieved on 2026-11-16. Its MIT LICENSE is retained. The original project credits Şuayp Talha Kocabay and collaborators; source files derived from that work remain subject to the upstream license.

Upstream research: [s-means research write-up](https://suayptalha.github.io/s-means-blog/).
Conceptual antecedent: Meta FAIR's [e-means](https://github.com/facebookresearch/faiss/tree/main/contrib/e_means), published as arXiv:2611.09501.

Sven-means modifications, tests, and benchmark harness are separate derivative work by the Svyable project. Reported measurements from the upstream repository are not independently verified sven-means results.
