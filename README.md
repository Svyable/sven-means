# sven-means

A research-oriented, attributable refactor and experimental extension of [s-means](https://github.com/suayptalha/s-means), itself inspired by Meta FAIR's [e-means](https://github.com/facebookresearch/faiss/tree/main/contrib/e_means).

This repository is under active development. We preserve upstream MIT licensing and distinguish tested results from hypotheses. See the development branches/commits for the implementation and benchmarks.
